# Glue domain language

Use these terms in code, docs, issues and UI. A new term goes here first. Layout and reading rules: [docs/agents/domain.md](docs/agents/domain.md).

| Term        | Meaning                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------- |
| App         | The product a Glue workspace describes. Glue holds the why for one or more apps.                    |
| Concept     | The structured record of why an app is built the way it is. The single source of truth for one app. |
| Decision    | One choice with its reason, date and owner. Links to the evidence behind it.                        |
| Guardrail   | A rule every change to the app must respect.                                                        |
| Insight     | A finding from UX research or real usage data. Decisions cite insights.                             |
| Integration | A sync with an outside tool that reads from or writes to a Concept.                                 |
